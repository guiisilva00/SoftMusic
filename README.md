🎵 Overview — Soft Music

O Soft Music é uma aplicação web desenvolvida para entusiastas e amantes da música organizarem e gerenciarem suas seleções musicais e playlists personalizadas. A plataforma oferece uma interface intuitiva e centralizada para o gerenciamento de faixas, permitindo catalogar informações detalhadas como artista, álbum, ano de lançamento e gênero musical de forma simples e eficiente.

✨ Destaques do Projeto
Gerenciamento Completo de Faixas (CRUD): Cadastre novas faixas, visualize a lista completa, edite dados existentes e remova itens da biblioteca de forma dinâmica.

Organização Detalhada: Organize o acervo catalogando informações como título da música, artista(s), categoria/gênero, álbum e ano de lançamento.

Interface Limpa e Responsiva: Visualização fluida em formato de tabela interativa com ações rápidas para facilitar a navegação do usuário.

Integração com Banco de Dados: Persistência segura e ágil das informações utilizando MySQL através de conexões PDO.
